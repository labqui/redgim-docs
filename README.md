# REDGIM - documentação pública

Este repositório **publica o site** do REDGIM: o manual do usuário, o visualizador de
resultados e os instaladores. Ele é o destino do GitHub Pages, e nada além disso.

## O site

**https://labqui.github.io/redgim-docs/**

- Manual do usuário, em português e em inglês
- Visualizador de `.gim` que roda no navegador, sem instalar nada
- Exemplos de análises reais, prontos para abrir

## Sobre o conteúdo deste repositório

Tudo aqui é **gerado**: são os arquivos já compilados do site. O código-fonte do REDGIM e
o texto do manual não ficam neste repositório, e cada publicação **reescreve** este
conteúdo por inteiro.

Por isso, correções não devem ser enviadas como PR aqui - elas se perderiam na publicação
seguinte. Encontrou um erro no manual ou no aplicativo? Abra uma
[issue](../../issues), que é o canal certo.
