How to get it

REDGIM is free. There is no paid edition, no per-seat licence and no trial period.

Android​

The app is published on Google Play, in Portuguese and in English.

Get it on Google Play

Desktop​

Desktop REDGIM is the same app, with the same calculations and the same charts. Each installer already carries everything it needs: no Java to install, no other dependency.

SystemDownload
Windows 10 or 11REDGIM-windows-x64.msi
Linux (Debian, Ubuntu and derivatives)REDGIM-linux-x64.deb
macOS with Apple Silicon (M1 or newer)REDGIM-macos-arm64.dmg
macOS with an Intel processorREDGIM-macos-x64.dmg

The addresses above always point to the latest version, so you can bookmark them.

Which of the two macOS files

In the Apple menu, under About This Mac, look at the processor or chip line. If it says Apple M1, M2, M3 or later, use the arm64 one. If it says Intel, use the x64 one.

Installing​

Windows. Open the .msi and follow the installer. Updating to a new version replaces the previous one, without duplicating it in the programs list.

Linux. Install through the graphical package manager, with a double click, or from a terminal:

sudo dpkg -i REDGIM-linux-x64.deb

macOS. Open the .dmg and drag REDGIM into Applications. The first time you open it, the system warns that the app comes from an unidentified developer: right-click it, choose Open, and confirm. You only need to do this once.

Why macOS warns

REDGIM is not yet signed or notarised by Apple, which requires a paid developer account. The warning is about that, not about the contents of the app.

Scientific export on the desktop

Exporting the charts in scientific format uses the system's Python, with the matplotlib library. Without both installed, the rest of the app works normally, but that particular export reports that Python is missing. This does not apply on Android.

Why the result does not depend on the device​

The calculation, that is, histograms, PCA, PLS and the metrics, lives in a shared base, written once. What changes between platforms is the outer layer: camera, files, sharing.

That matters for a practical reason: the same analysis, with the same images and the same regions, produces the same numbers on any platform. A .gim generated on Android opens the same on the desktop.

Without installing anything​

To look at a finished analysis you do not need the app: this site's Results Viewer opens any .gim in the browser, including on a computer. It does not capture images or process a model, but it shows the whole analysis.
