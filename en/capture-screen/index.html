The capture screen

This is the screen you spend the most time on. It shows the image, the regions marked on it, and almost nothing else: what drives it is a finger on the photo.

The top bar changes with the selection​

With no region selected, the bar belongs to the analysis:

ElementWhat it does
Back arrowLeaves the capture screen. If the analysis is unsaved, it asks before discarding
Analysis nameTap it to save or rename, and from there go on to exporting
Camera, with a numberOpens the gallery. The number is how many images the analysis has
GearSets the size and shape of the regions. In Prediction Mode it is also the way to the optimiser

Select a region and the same bar becomes the editing one, in the colour of that region's type:

ElementWhat it does
XClears the selection
TitleThe region's name; while you drag, it says it is moving
SubtitleThe position of the region's centre, in image pixels
Clock or info iconOpens the region's data. The clock means the histogram is still being computed
GearThe same size and shape settings

The round button changes role​

The floating button in the corner is not always the same thing:

  • analysis not saved yet: it saves;
  • a region selected: it opens that region's form, with a + when the region is new and a pencil when it already exists. The colour is the region type's;
  • nothing selected: it processes the analysis.

The five gestures​

None of them is hidden behind a menu.

Select and deselect

A tap on a region selects it, and the top bar switches to the editing actions. A tap on the image, outside any region, clears the selection.

Create a region

A long press on the image creates a new region at that point, already selected. If the chosen point would not fit the region entirely, it lands on the nearest valid position.

Move and delete

On an already selected region, press and drag to move it. Dropping it on the bin that shows up at the bottom deletes the region.

Zoom in

A double tap on the image toggles between the whole photo and a magnified view. On the selected region, it zooms in on it and centres it.

Frame it

With the photo magnified, dragging moves the framing around, and pinching with two fingers adjusts the zoom. While a region is being dragged the zoom is locked, so one gesture does not run over the other.

The way back

With a region selected, the device's back button only clears the selection. Only after that does it leave the capture screen, and then it asks before discarding the analysis.

The ruler around the image​

The marks along the edges follow the photo as you zoom and pan. They are there so you know where you are looking when the image is well magnified, and to compare the position of regions that ended up far apart.

Size and shape of the regions​

The gear sets both at once, and it applies to every region in the analysis: they are the same size by construction, which is what makes the histograms comparable with each other.

The default is a 45 pixel square. The maximum follows the image, so a region can never grow beyond what the photo can support.
